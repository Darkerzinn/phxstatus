Política de Privacidade

Última atualização: 16 de novembro de 2026

Importante: esta Política reflete as informações fornecidas até agora. Confirme os itens ainda pendentes sobre dados recebidos, banco de dados, retenção e exclusão antes de divulgar.

1. Quem somos

PHX Status é um projeto independente de bot para Discord. Responsável pelo projeto: soaresdev. Contato de privacidade: carlosdevofc2025@gmail.com.

2. Dados que podem ser tratados

Para funcionar em vários servidores, o bot utiliza informações e configurações associadas a cada servidor. Cada servidor define seu próprio canal de logs. Segundo o responsável pelo projeto, o banco de dados guarda somente informações dos servidores. Ao processar comandos, o bot também recebe os dados de interação enviados pelo Discord; isso não significa, por si só, que esses dados sejam persistidos no banco.

3. Finalidades

Os dados estritamente necessários poderão ser utilizados para executar comandos, manter configurações do servidor, responder a solicitações, prevenir abuso e diagnosticar falhas. Não declare finalidades que seu bot não executa.

4. Armazenamento e retenção

O banco de dados guarda informações associadas aos servidores e às configurações necessárias ao funcionamento multisservidor, incluindo o canal de logs definido por cada servidor. O bot é hospedado na Discloud, mas ainda é necessário confirmar onde o banco de dados fica hospedado, por quanto tempo essas configurações são mantidas e como são excluídas, inclusive quando o bot é removido de um servidor.

5. Compartilhamento

O bot é hospedado na Discloud, que fornece a infraestrutura para sua execução e pode processar os dados necessários à prestação desse serviço. Os registros enviados pelo bot são direcionados aos canais de logs configurados por cada servidor e ficam sujeitos às regras e à retenção do Discord e dos administradores desses servidores. Se o banco de dados usar um provedor diferente da Discloud, esse provedor também deve ser identificado nesta Política.

6. Segurança

Adotamos medidas razoáveis para proteger as informações tratadas. Nenhum sistema é completamente livre de riscos; evite inserir dados pessoais ou sensíveis em comandos do bot.

7. Direitos e solicitações

Para solicitar informações, correção ou exclusão de dados pessoais tratados pelo projeto, entre em contato por carlosdevofc2025@gmail.com. Descreva como a pessoa pode comprovar que administra o servidor ou a conta relacionada ao pedido, sem enviar senhas ou tokens.

8. Menores de idade

O bot não foi desenvolvido para solicitar intencionalmente dados pessoais de crianças. Se você acredita que dados foram enviados indevidamente, entre em contato pelo endereço informado.

9. Alterações

Esta Política poderá ser atualizada para refletir mudanças no bot, na infraestrutura ou nas exigências legais. A versão vigente ficará disponível nesta página.
