# PHX Status — site estático

## Arquivos
- `index.html`: página inicial
- `terms.html`: Termos de Serviço
- `privacy.html`: Política de Privacidade
- `styles.css`: identidade visual responsiva
- `logophxstatus.png`: logo exibida na barra de navegação

## Antes de publicar
1. Substitua `[SEU NOME OU NOME DO RESPONSÁVEL]` e `[SEU E-MAIL DE CONTATO]`.
2. Revise a Política de Privacidade para refletir exatamente os dados que o código do bot recebe, armazena, registra, compartilha e elimina.
3. Confirme que a forma de monitoramento respeita os termos e as permissões dos serviços monitorados.
4. Publique os arquivos em hospedagem HTTPS pública.

## GitHub Pages
1. Crie um repositório público no GitHub, por exemplo `phx-status-site`.
2. Envie os arquivos do site, incluindo `logophxstatus.png`, para a raiz do repositório.
3. Abra Settings → Pages.
4. Em Build and deployment, escolha Deploy from a branch, selecione `main` e `/ (root)`, e salve.
5. Aguarde a publicação. O endereço será parecido com `https://SEU-USUARIO.github.io/phx-status-site/`.

## URLs para o Discord Developer Portal
